# Historical baseline snapshots

These files are retained as compact audit evidence from previous repository analyses. They are not live outputs and are not regenerated by the normal test workflow.

- `data_quality_audit.json`: original source-data audit snapshot; non-numeric missing-value markers were normalized to JSON `null` so the file is valid JSON.
- `one_week_validator_crosscheck.json` and `full_horizon_validator_crosscheck.json`: historical comparison between experiment and independent-validator results. The full-horizon mismatch is unresolved and tied to MGT rule expiry.
- `mgt_effective_date_mismatches.csv`: detailed historical MGT effective-date mismatch records.
- `retiming_experiment_1w.csv` and `retiming_experiment_1w_summary.json`: exploratory retiming sensitivity results; not a proof of dominance or a shared-resource optimization result.
